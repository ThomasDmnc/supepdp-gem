# Security Policy

## Supported versions

Only the latest released version is supported. The maintainer may yank a version
at any time (see the disclaimer in the [README](README.md)); pin a version if you
depend on it.

## Reporting a vulnerability

Please **do not** open a public issue for anything sensitive (e.g. a
credential-handling problem). Email the maintainer at **thomas.demoncy@gmail.com**
with details and steps to reproduce; you'll get an acknowledgement as soon as
possible.
